# Radio DX

국내·해외 라디오 송신소 위치와 대한민국 성남시 분당구 기준 거리를 보여주는 한국어 웹문서입니다.

## 페이지

- `index.html`: 국내 라디오. 수도권 주요 22개 방송, 관악산·남산·소래·남양 4개 송신소.
- `overseas.html`: 해외 라디오. 일본 닛케이·NHK 5개 방송, 4개 송신소.

`index.html`을 브라우저에서 열면 됩니다. 빌드는 필요하지 않으며 D3만 CDN에서 불러옵니다. 지도 지형과 행정구역 데이터는 저장소에 포함되어 있습니다. 지도의 선 중간에는 대권거리를 표시하며, 송신소 라벨에 마우스를 올리거나 키보드로 초점을 맞추면 위경도를 확인할 수 있습니다. 모바일에서는 라벨을 탭할 수 있습니다.

방송 목록은 `stations.js`, 지도와 목록 표시는 `app.js`, 화면 스타일은 `style.css`에서 관리합니다.

## GitHub Pages

저장소 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main`과 `/ (root)`를 선택하면 게시할 수 있습니다. 설정 후 기본 주소는 `https://surajang.github.io/radio-dx/`입니다.

## 데이터

분당구청 부근(37.3827, 127.1188)에서 각 송신소까지 대권거리를 계산합니다. 국내는 0.1 km, 해외는 1 km 단위로 반올림합니다. 실제 전파의 이동 거리나 수신 가능 범위를 의미하지 않습니다. 좌표·방송 정보 출처는 각 페이지 하단에 있습니다. 국내 목록은 전국의 모든 방송을 망라하지 않으며, 해외 목록은 현재 일본 송신소로 구성되어 있습니다.

지도 지형은 Natural Earth의 public domain 데이터를 사용합니다. 국내 행정구역은 southkorea-maps에서 제공하는 KOSTAT 2013 시군구 자료를 사용하며, 현재 행정경계와 다를 수 있습니다. D3의 라이선스는 ISC입니다.
